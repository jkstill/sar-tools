
All that is needed to prepare the sar files are these two files:

- asp.sh
- sadf-12.4.5
  - only needed for Linux versions 7 and 8


Copy the files to the same directory and run the following command:

```bash
chmod +x asp.sh
./asp.sh -d csv
```

When it is finished, just zip of the csv directory and submit the zip file for processing.
